Your monitoring tells you when a call fails. It does not tell you when a model you depend on quietly stops being callable, or when it still answers but no longer obeys the contract your code was written against. This agent probes every dependency on a schedule, replays behaviour contracts against the ones that answer, and grades each on correctness, latency and real published price.
